# WezTerm

- WezTerm Nightly draws the terminal on macOS and Windows. WezTerm shows its native tab bar. Leave Ctrl+Q available to the Herdr remote client. macOS opens fullscreen and Karabiner lets the original Ctrl keys through. Windows starts in a regular window with resize borders.
- The same Lua config runs on both platforms. The `darwin` mise environment links the config directory and `wsl` copies the Lua files and background image into Windows. The image path is relative to `wezterm.config_dir`. Windows launches the WSL login shell with `wsl.exe --exec /home/uvu1/.nix-profile/bin/zsh`. The absolute path is needed because WSL's default PATH does not contain the Nix profile. An interactive login shell activates mise. Connect to remote Herdr with `herdr --remote <target>`.
- Keep startup and platform shell settings in `wezterm.lua`, visual settings in `appearance.lua`, and keyboard, mouse, and QuickSelect settings in `keybinds.lua`.
- Ctrl+B is the WezTerm leader for t, w, and 1–9. Press Ctrl+B twice to send Ctrl+B to the terminal. Ctrl+1–9 sends the Herdr prefix followed by the tab number. Ctrl+Shift+X is sent as CSI u to Herdr's copy mode. Shift+Enter sends ESC+CR for Claude Code. Alt+[ and Alt+] use CSI u for Neovim's buffer bindings in `nvim/lua/config/keymaps.lua`.
- Validate Lua and key assignments with `wezterm --config-file <path-to-wezterm.lua> show-keys --lua`. Run the respective mise dotfiles status and dry run before applying on macOS or WSL. After applying, test startup, fullscreen, tab and copy shortcuts, QuickSelect, Shift+Enter, and Neovim's Alt bracket bindings on each OS.
