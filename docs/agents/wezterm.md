# WezTerm

- WezTerm Nightly draws the terminal on macOS and Windows. Herdr owns splits, tabs, workspaces, notifications, and session persistence. Keep the WezTerm tab bar disabled and leave Ctrl+Q available to Herdr. macOS opens fullscreen and Karabiner lets the original Ctrl keys through. Windows starts in a regular window with a title bar.
- The same Lua config runs on both platforms. The `darwin` mise environment links the config directory and `wsl` copies the Lua files and background image into Windows. The image path is relative to `wezterm.config_dir`. Windows launches the WSL login shell with `wsl.exe --exec /home/uvu1/.nix-profile/bin/zsh`. The absolute path is needed because WSL's default PATH does not contain the Nix profile. An interactive login shell activates mise before starting Herdr.
- Keep startup and platform shell settings in `wezterm.lua`, visual settings in `appearance.lua`, and keyboard, mouse, and QuickSelect settings in `keybinds.lua`.
- The tab shortcuts send Herdr's existing prefix sequences. Keep them aligned with `herdr/config.toml` and the Herdr defaults for close and switch tab. Ctrl+Shift+X is sent as CSI u to Herdr's copy mode. Shift+Enter sends ESC+CR for Claude Code. Alt+[ and Alt+] use CSI u for Neovim's buffer bindings in `nvim/lua/config/keymaps.lua`.
- Validate Lua and key assignments with `wezterm --config-file <path-to-wezterm.lua> show-keys --lua`. Run the respective mise dotfiles status and dry run before applying on macOS or WSL. After applying, test startup, fullscreen, tab and copy shortcuts, QuickSelect, Shift+Enter, and Neovim's Alt bracket bindings on each OS.
