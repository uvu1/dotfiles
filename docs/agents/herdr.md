# herdr

- Herdr's prefix is `ctrl+q`. Connect to remote Herdr with `herdr --remote <target>`. WezTerm sends Ctrl+Q followed by the tab number for Ctrl+1–9. Keep the prefix and tab switching aligned with `wezterm/keybinds.lua`. Ctrl+Shift+X is sent as CSI u and handled by Herdr's copy mode. `mise/dotfiles/.config/herdr/scripts/copy-last-output.sh` (`prefix+c`) finds the previous command's output by walking rows: it skips the current prompt block up to the blank line `add_newline` emits, then looks for the preceding line starting with `❯`. That symbol and the three-line prompt shape come from `mise/dotfiles/.config/starship.toml` (`format`, `add_newline`, `[character]`), which stays the single source of truth — change the script with it; `copy-last-output.sh --stdin` runs the parser alone for testing. herdr writes back to `~/.config/herdr`, so `mise.unix.toml` links only `config.toml` and `scripts/`. Do not run `herdr integration install` for claude or codex: it writes absolute paths into `~/.claude/settings.json`, which is a symlink into this repository, and into `~/.codex`. The integrations are vendored instead: the hook scripts herdr generates live at `mise/dotfiles/ai/claude/hooks/herdr-agent-state.sh` and `mise/dotfiles/ai/codex/herdr-agent-state.sh`, `settings.json` and `codex/hooks.json` call them through `~`, and `codex/config.toml` sets `features.hooks = true`. After a herdr upgrade, if `herdr integration status` reports them outdated, regenerate them with `CLAUDE_CONFIG_DIR` / `CODEX_HOME` pointed at a scratch directory and copy the scripts over. Agent notifications come from herdr's own state detection, so Claude Code and Codex keep their default notification settings.
- Run `herdr config check` after herdr config changes; it reports conflicting and invalid keybindings. Use a throwaway `HOME` to check an uncommitted copy.
